# 🌐 Serviços de Linguagem e Bots da Azure

## 🧠 Language Studio

O **Language Studio** possui uma interface de usuário que permite explorar diversos recursos de linguagem. A plataforma fornece insights como:

- 🌍 **Idioma predominante**
- 😊 **Sentimento**
- 📍 **Localidade**
- 📝 **Frases-chave**

Com essas informações, a **inteligência artificial** pode traçar **métricas relevantes**.

### 💬 Funcionalidades adicionais

Além de inserir documentos, também é possível:

- ❓ Adicionar **perguntas e respostas**
- 🤖 Utilizar **bate-papo integrado**

🔧 Para começar a usar:
1. Crie um **recurso no portal do Azure**
2. Acesse: [language.cognitive.azure.com](https://language.cognitive.azure.com)

- 📊 **Gerenciamento de bots**

- 🔗 Integração com **AI Language**

## 🗣️ Compreensão de Linguagem Coloquial

A **IA é capaz de entender linguagem natural**. Essa habilidade se baseia em três componentes principais:

1. 🧾 **Declaração**
2. 🧩 **Entidade**
3. 🎯 **Intenção**

🔍 **Programadores de IA** precisam compreender bem esses conceitos para construir interações eficazes.
